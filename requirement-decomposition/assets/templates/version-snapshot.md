## 1. 怎么生成

不要手写。手抄的快照必然与实际漂移，那时它记录的不再是基线，而是某人上次记得更新的时刻。

```bash
python3 scripts/validate_requirements.py ./需求文档 --snapshot 2026-08-09 >> ./需求文档/04-版本快照.md
```

脚本读取各文档头部的「文档版本」行生成。缺这一行的产物不会出现在快照里，跑 `--only C11` 查是哪几份。
